# 《梦境行者》游戏策划案

## 一、核心玩法设计

### 1. 核心循环
1. **抽取本层效果**：从3个固定效果中随机获得1个（整层生效）。  
2. **首次赐福**：从5种赐福中随机抽取3个，从中选择1个。  
3. **探索路线**：依次经历以下节点（顺序固定）：  
   - 小怪 / 随机事件（3次） → 商店 → 精英 → 第二次赐福 → BOSS  
4. **第二次赐福与结局分支**：  
   - 正常选择：从5种赐福中随机抽取3个，选1个。  
   - 若持有结局卡“大梦”，可在此处上交，将BOSS替换为隐藏BOSS“梦魇”。  
5. **挑战BOSS**：胜利则通关；失败则游戏结束，本局所有进度不保留。

### 2. 本层效果（3选1，随机获得）
| 名称 | 效果 |
|------|------|
| 与我同去 | 玩家与所有敌怪的最大生命值变为原值的50%，当前生命值等比缩放（向下取整）。 |
| 回响形态 | 玩家每打出一张卡牌，其效果触发两次（费用只支付一次）；每个敌怪每回合行动两次（行动顺序不变）。 |
| 至死不休 | 玩家生命上限翻倍（当前生命值也翻倍）；每当任意敌怪死亡时，玩家立即失去10点生命值（可致死）。 |

### 3. 赐福（每次从以下5种中随机3个，选1个）
| 赐福 | 效果 |
|------|------|
| 删除牌 | 从牌组中删除1张牌（永久）。 |
| 稀有卡 | 从3张稀有卡牌中选取1张加入牌组。 |
| 随机遗物 | 获得1个随机遗物（普通80%，史诗20%）。 |
| 自选本层效果 | 从3个本层效果中自选1个（取代本层原有的随机效果）。 |
| 生命提升 | 最大生命值+20，并恢复等量当前生命。 |
### 4. 地图生成
游戏采用 **8 层** 地图结构，每层独立生成一张横屏滚动地图，玩家从底层（第1层）向上攀爬至第8层击败最终BOSS。每层地图由若干列（阶段）和行（路径分支）组成，类似《杀戮尖塔》的节点式前进。

### 1. 地图结构总览
- **节点数**：8 个节点
- **显示方式**：横屏，从左至右为前进方向，玩家节点高亮
- **起点**：每层最左侧固定为“**起始赐福节点**”（即核心循环中的“首次赐福”）  
- **终点**：每层最右侧固定为“**BOSS节点**”
- **中间节点**：随机生成小怪、精英、商店、随机事件

### 2. 节点类型及图标（横屏示意）
| 节点类型 | 图标 | 说明 |
|----------|------|------|
| 赐福 | 🌟 | 触发赐福选择 |
| 小怪 | 👾 | 普通战斗，掉落金币、经验、卡牌 |
| 精英 | 👹 | 高难度战斗，掉落更多金币、经验、稀有/史诗卡 |
| 商店 | 🛒 | 可购买卡牌、遗物，删除卡牌 |
| 随机事件 | ❓ | 触发随机事件（如沉睡商人、温暖被窝等） |
| BOSS | 👑 | 每层最终战斗 |

### 3. 地图生成规则
- 第一列两个节点，赐福节点，2、3、4列2-3节点，5列为商店，6列为精英，7列为赐福，8列为boss节点，2、3、4列生成时50%几率2节点，50%几率3节点，每个节点有50%只与下一列一个节点相连，50%几率与下一列两个节点相连，且保证不会出现死路。

- 生命值：100（当前生命=最大生命）  
- 初始金币：100

## 三、战斗规则

### 1. 回合流程
每轮分为：**玩家回合 → 敌怪回合**  

**玩家回合**：  
1. 结算回合开始时的特殊效果（如“不息”的伤害）。  
2. 获得费用（基础3点，可受效果影响）。  
3. 从抽牌堆抽5张牌作为手牌（若抽牌堆不足，则洗混弃牌堆后继续抽）。  
4. 出牌阶段（任意顺序，可随时查看费用和手牌）。  
5. 结算回合结束时的特殊效果。  
6. 费用清零，手牌中所有未打出的牌进入弃牌堆。  

**敌怪回合**：  
1. 结算敌怪回合开始时的特殊效果。  
2. 每个敌怪按自身行动模式依次行动（若“回响形态”则每个敌怪行动两次）。  
3. 结算敌怪回合结束时的特殊效果。  

### 2. 卡牌流程
- 战斗开始时，将牌组中所有卡牌洗入抽牌堆。  
- 卡牌使用后进入弃牌堆。  
- 抽牌堆为空时，将弃牌堆所有卡牌洗入抽牌堆（不改变顺序规则）。  

### 3. 伤害计算
- 对敌伤害 = max( 玩家攻击力 - 敌怪防御力 , 玩家攻击力 × 10% )  
- 对玩家伤害 = max( 敌怪攻击力 - 玩家防御力 , 敌怪攻击力 × 10% )  
- 结果向下取整，至少为1。  

### 4. 胜负条件
- 失败：玩家生命值 ≤ 0。  
- 通关：击败最终BOSS（或隐藏BOSS）。

## 四、等级系统（共4级）
- 每级所需经验：10（1→2，2→3，3→4）  
- 经验掉落（每场战斗）：小怪组8，精英组12，BOSS组16  

### 等级奖励（升级时立即生效）
| 升级 | 属性变化 | 生命恢复 |
|------|----------|----------|
| 1→2 | 攻击力 60 → 80 | 恢复最大生命值的5% |
| 2→3 | 防御力 50 → 70 | 恢复最大生命值的5% |
| 3→4 | 选择：生命值 100 → 120  **或** 获得1张自选史诗卡牌 | 恢复最大生命值的5% |
| 4级（满级） | 无属性提升 | 恢复最大生命值的10%（仅在升满级时触发一次） |

> 注：生命恢复均为**立即恢复当前生命值**，不超过最大生命。

## 五、卡牌系统

### 1. 卡牌类型
- **攻击卡**：对敌怪造成伤害。  
- **技能卡**：施加状态或产生效果，使用后进入弃牌堆。  
- **能力卡**：施加持续整场战斗的状态，使用后**移出战斗**（不进入弃牌堆）。  
- **负面牌**：对自身产生负面效果（当前版本未实装）。  

### 2. 稀有度与数量
| 稀有度 | 数量 | 掉落规则 |
|--------|------|----------|
| 初始卡 | 3种（打击×5，防御×5，睡觉×1） | 游戏开始自带 |

| 结局卡 | 1种（大梦） | 商店购买或随机事件获取 |

## 六、怪物机制

### 通用说明
- 所有怪物的攻击/防御计算遵循伤害公式。  
- 状态效果（腐化、虚弱、沉睡等）若无特别说明，持续到战斗结束，可叠加。

|------|------|------|------|----------|

### 3. 精英怪（每场掉落12经验）

#### 梦境守卫者
- 生命：280，攻击：50，防御：20  
- 行动循环：  
  1. **壁垒**：自身防御+30（持续整场战斗）  
  2. **重击**：造成150%攻击力的伤害  
  3. **震荡波**：造成100%攻击力的伤害，并使玩家防御-15（可叠加）  
  然后重复步骤1。

#### 沉睡巨像
- 生命：332，攻击：45，防御：80  
- 行动：  
  - 前2回合**沉睡**（不行动，免疫控制）。  
  - 受到**3次伤害**后觉醒（计数跨回合）。  
  - 觉醒后循环：**召唤沉睡石像** → **打击**（100%攻击） → **强化**（所有敌方单位攻击力+15） → 重复。  

**沉睡石像**（召唤物）  
- 生命：80，攻击：45，防御：40  
- 首回合沉睡；受到3次伤害后觉醒；觉醒后循环：**打击**（100%攻击） → 施加**腐化** → 重复。  

### 4. BOSS（每场掉落16经验）

#### 沉睡之主
- 生命：500，攻击：60，防御：60  
- 行动（固定顺序）：  
  1. **梦魇凝视**：造成100%攻击力的伤害，并施加**腐化**。  
  2. **深度沉睡**：自身恢复30点生命。  
  3. **噩梦爆发**：施加**噩梦**状态（本回合内，玩家手牌卡牌在打出前隐藏卡牌名称与效果，仅显示“？？？”）。  
  然后重复。

#### 梦魇（隐藏BOSS，由“大梦”触发）
- 生命：1，攻击：0，防御：0  
- **特性**：无法被任何方式攻击或伤害；12回合后自动死亡（玩家胜利）。  
- **行动（每回合固定）**：  

| 回合 | 行动 | 详细 |
|------|------|------|
| 1 | 唤梦 | 召唤2个**本层随机小怪**（从当前层小怪组中选，非精英） |
| 2 | 虚弱诅咒 | 对玩家施加**腐化**和**虚弱**（各1层） |
| 3 | 重塑 | 将场上所有非BOSS敌方单位随机变化为其他本层小怪（保留当前生命值百分比） |
| 4 | 沉眠 | 使所有单位（包括玩家）**沉睡**一回合；然后所有敌方单位回复30%最大生命 |
| 5 | （空） | 无行动 |
| 6 | 沉沦·小 | 对玩家造成 **2倍于当前场上所有小怪生命值之和** 的伤害，然后强制消灭所有小怪 |
| 7 | 唤梦·精英 | 召唤1个**本层随机精英**（从当前层精英中选） |
| 8 | 虚弱诅咒 | 同第2回合 |
| 9 | 重塑·精英 | 将场上所有非BOSS敌方单位随机变化为其他本层精英（保留当前生命值百分比） |
| 10 | 沉眠 | 同第4回合 |
| 11 | （空） | 无行动 |
| 12 | 沉沦·大 | 对玩家造成 **0.5倍于当前场上所有精英生命值之和** 的伤害，然后强制消灭所有精英；之后梦魇死亡，玩家胜利 |

> 注：若回合中无对应单位（如第6回合无小怪），则沉沦伤害为0。

## 九、随机事件（出现在小怪节点，替代战斗）

### 1. 沉睡的商人
- 描述：商人在梦境中熟睡，背包敞开。  
- **选择1：偷金币** → 获得50金币，但下一场战斗中防御力-10（可叠加）。  
- **选择2：叫醒商人** → 获得1张随机普通卡。  

### 2. 温暖被窝
- 描述：突然出现的柔软床铺。  
- **选择1：休息** → 恢复30%最大生命值，但下一场战斗中敌人先行动（第一回合跳过玩家回合）。  
- **选择2：离开** → 无效果。  

### 3. 遗忘之泉
- 描述：白雾缭绕的泉水，触碰会遗忘部分记忆。  
- **选择1：喝下** → 随机删除1张牌（永久），最大生命值+10（并恢复等量当前生命）。  
- **选择2：离开** → 无效果。

## 十、补充规则与澄清

1. **生命值变动**：所有“失去生命”效果均可致死，且触发相关遗物（如燃血）。  
2. **状态叠加**：腐化、虚弱、困倦等无特殊说明均可叠加，每层独立生效。  
3. **费用管理**：费用最低为0，不会为负；预借类负面效果若导致下回合费用为负，则按0计算。  
4. **抽牌数量**：每回合基础抽5张；预借抽卡、迷惑等效果影响的是“本应抽取的数量”，最少为0张。  
5. **“本场战斗”与“永久”**：  
   - 本场战斗：效果在战斗结束后消失。  
   - 永久：保留至游戏通关或失败。  
6. **多敌怪死亡**：“至死不休”效果中，每个敌怪死亡独立触发10点生命损失。  
7. **随机选择**：所有“随机抽取/选择”若未说明权重，默认等概率。
