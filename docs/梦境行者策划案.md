## 二、核心玩法设计

### 1. 核心循环

抽取本层效果（3种效果抽一种）→选取赐福（5种赐福，抽三种，从中选一个）→收集卡牌/遗物/提升属性→选取赐福（5种赐福，抽三种，从中选一个）/提交结局卡牌→挑战boss→失败重来

赐福→小怪（问号）→小怪（问号）→小怪（问号）→商店→精英→赐福→BOSS

本层效果：

1.  与我同去：玩家和敌怪的血量变为50%。

2.  回响形态：玩家每张卡牌都会释放两次，敌怪每回合行动两次。

3.  至死不休：玩家生命上限翻倍，但敌怪死亡时玩家失去10点生命值。

赐福：

1.  删除你牌组一张牌

2.  从三张稀有卡牌中选择一张

3.  获得随机遗物

4.  自选本层效果

5.  提升你的最大生命20点

### 2. 职业设定（暂定一位）

攻击力：60

防御力：50

生命值：100

初始金币：100

### 3. 战斗规则

轮次：玩家回合→敌怪回合为一轮

玩家回合：结算特殊效果→获取费用（初始3点）→发牌（初始每次五张）→出牌→结算特殊效果→费用清零→手牌洗入弃牌堆

卡牌：战斗开始时将所有卡牌放入抽牌堆，卡牌使用后进入弃牌堆，抽牌堆的卡牌数量为0时，将弃牌堆所有卡牌打乱后放入抽牌堆。

敌怪回合：结算特殊效果→行动→结算特殊效果

伤害计算：伤害值=max（攻击-防御，攻击\*10%）

失败条件：玩家血量≤0；

通关条件：击败最终 BOSS

### 4. 卡牌系统

卡牌类型：

从功能：

1.  攻击卡：对敌人造成伤害

2.  能力卡：对自身施加特殊状态，使用后在本场战斗移除卡牌

3.  技能卡：对自身或敌方施加特殊状态，使用后不移除卡牌

4.  负面牌：对自身造成负面效果的卡牌

从卡牌稀有度

1.  初始卡牌：三种

2.  普通：七种

3.  稀有卡：五种

4.  史诗卡：三种

卡牌掉落：

1.  击杀小怪80%掉落普通稀有度的卡牌，20%掉落稀有稀有度的卡牌，从三张选一张

2.  击败精英80%掉落稀有稀有度的卡牌，20%掉落史诗稀有度的卡牌，从三张选一张

### 5. 怪物机制

小怪：

1.  史莱姆

生命：120

攻击：40

防御：40

行动逻辑：

第一回合：攻击（造成攻击力100%的伤害）

攻击后下一回合有30%概率继续攻击，70%的概率施加负面效果

负面效果：本场战斗减少你10点防御力

### 6. 商店系统

出售3普通卡牌，3稀有卡牌，1结局卡牌，3遗物，可删除卡牌
